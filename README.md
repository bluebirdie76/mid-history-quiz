# 중2 역사 퀴즈 — 지역 세계의 교류와 발전

비상교육 중학 역사① 3-3, 4-1, 4-2, 4-3 단원 대비 문제풀이 웹앱.

- 총 70문항 (5지선다 55 · 단답형 12 · 서술형 3)
- 즉시 채점 · 상세 오답 해설
- 진행 상황 로컬 자동 저장
- 라이트/다크 테마

## 로컬에서 열기

정적 서버로 서빙해야 스크립트가 로드됩니다 (`file://` 직접 열기는 브라우저 정책상 안 됨).

```bash
python -m http.server 8000
# 이후 http://localhost:8000 열기
```

## GitHub Pages 배포

이 저장소를 GitHub에 올린 뒤:

3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 로 접속 가능
